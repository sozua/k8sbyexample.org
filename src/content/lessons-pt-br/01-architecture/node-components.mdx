<Intro>
  <p>Worker nodes executam suas cargas de trabalho. Cada node possui: kubelet (ciclo de vida do Pod), kube-proxy (rede), e container runtime (executa containers). Os nodes se registram no control plane e recebem trabalho via API Server.</p>
</Intro>

      <p slot="docs">O kubelet é o agente do node. Ele observa Pods atribuídos ao seu node, inicia containers, executa probes e reporta status. Ele não gerencia containers não-Kubernetes.</p>
      <Fragment slot="code">
```bash
$ systemctl status kubelet
● kubelet.service - kubelet: The Kubernetes Node Agent
   Loaded: loaded (/lib/systemd/system/kubelet.service; enabled)
   Active: active (running) since Mon 2024-01-15 10:00:00 UTC
```

    <Row last terminal>
      <p slot="docs">Cordon marca um node como não-agendável. Novos Pods não serão alocados nele, mas Pods existentes continuam rodando.</p>
      <Fragment slot="code">
```bash
$ kubectl cordon node-1

$ kubectl get nodes
NAME     STATUS                     ROLES    AGE

node-2   Ready                      worker   30d
```
