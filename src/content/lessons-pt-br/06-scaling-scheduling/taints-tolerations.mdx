<Intro>
  <p>Taints marcam nós para repelir Pods; tolerations permitem que Pods sejam agendados em nós com taint. Diferente de affinity (atrair Pods para nós), taints funcionam por repulsão. Use para: nós dedicados, nós GPU, manutenção, prevenir workloads em hardware específico.</p>
</Intro>

<table class="example-table">
  <tbody>
    <FileHeader filename="taint-effects.yaml" />
    <Row last>
      <p slot="docs">Três efeitos de taint: <code>NoSchedule</code> (novos Pods não serão agendados), <code>PreferNoSchedule</code> (preferência suave para evitar), <code>NoExecute</code> (Pods existentes são despejados, novos Pods não serão agendados).</p>
      <Fragment slot="code">
```bash
kubectl taint nodes worker-1 dedicated=gpu:NoSchedule

kubectl taint nodes worker-2 preferred=lowpriority:PreferNoSchedule

kubectl taint nodes worker-3 maintenance=true:NoExecute
```
      </Fragment>
    </Row>
  </tbody>
</table>

    <FileHeader filename="toleration-exact.yaml" />
    <Row last>
      <p slot="docs">O operador <code>Equal</code> requer correspondência exata de chave e valor. Este Pod pode executar em nós com taint <code>dedicated=gpu:NoSchedule</code>. Sem esta toleration, seria rejeitado.</p>
      <Fragment slot="code">
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: gpu-workload
spec:
  tolerations:
    - key: "dedicated"
      operator: "Equal"
      value: "gpu"
      effect: "NoSchedule"
  containers:
    - name: ml-training
      image: ml-trainer:v1
      resources:
        limits:
          nvidia.com/gpu: 1
```
      </Fragment>
    </Row>
  </tbody>
</table>

    <FileHeader filename="toleration-exists.yaml" />
    <Row last>
      <p slot="docs">O operador <code>Exists</code> corresponde a qualquer taint com a chave especificada, independente do valor. Útil quando você não se importa com o valor específico do taint.</p>
      <Fragment slot="code">
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: tolerate-any-dedicated
spec:
  tolerations:
    - key: "dedicated"
      operator: "Exists"
      effect: "NoSchedule"
  containers:
    - name: app
      image: my-app:v1
---
tolerations:
  - operator: "Exists"
```
      </Fragment>
    </Row>

    <TerminalHeader cmd="kubectl taint nodes gpu-node-1 nvidia.com/gpu=true:NoSchedule" />
    <Row>
      <p slot="docs">Nós GPU dedicados para inferência LLM: aplique taint em nós GPU para prevenir workloads regulares de agendar lá. Também adicione labels para direcionamento via affinity. Taints repelem, labels atraem.</p>
      <Fragment slot="code">
```bash
$ kubectl taint nodes gpu-node-1 nvidia.com/gpu=true:NoSchedule
node/gpu-node-1 tainted

$ kubectl taint nodes gpu-node-2 nvidia.com/gpu=true:NoSchedule
node/gpu-node-2 tainted

$ kubectl label nodes gpu-node-1 gpu-node-2 accelerator=nvidia-a100
node/gpu-node-1 labeled
node/gpu-node-2 labeled
```
      </Fragment>
    </Row>
    <Row last terminal>
      <p slot="docs">Verifique se taints foram aplicados. Nós GPU agora rejeitam Pods sem tolerations correspondentes. Workloads regulares automaticamente agendam em nós apenas CPU.</p>
      <Fragment slot="code">
```bash
$ kubectl get nodes -L accelerator
NAME         STATUS   ROLES    ACCELERATOR
cpu-node-1   Ready    <none>
cpu-node-2   Ready    <none>
gpu-node-1   Ready    <none>   nvidia-a100
gpu-node-2   Ready    <none>   nvidia-a100

$ kubectl describe node gpu-node-1 | grep Taints
Taints:             nvidia.com/gpu=true:NoSchedule
```

    <FileHeader filename="llm-inference-deployment.yaml" />
    <Row>
      <p slot="docs">Deployment de inferência LLM com toleration GPU. A toleration permite agendamento em nós GPU com taint. Sem ela, o scheduler rejeita o Pod dos nós GPU.</p>
      <Fragment slot="code">
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: llm-inference
spec:
  replicas: 2
  selector:
    matchLabels:
      app: llm-inference
  template:
    metadata:
      labels:
        app: llm-inference
    spec:
      tolerations:
        - key: "nvidia.com/gpu"
          operator: "Equal"
          value: "true"
          effect: "NoSchedule"
```
      </Fragment>
    </Row>
    <Row last>
      <p slot="docs">Combine toleration com nodeAffinity para garantir que Pods rodem apenas em nós GPU. Toleration permite nós GPU; affinity requer eles. Solicite recurso <code>nvidia.com/gpu</code> para alocação real de GPU.</p>
      <Fragment slot="code">
```yaml
      affinity:
        nodeAffinity:
          requiredDuringSchedulingIgnoredDuringExecution:
            nodeSelectorTerms:
              - matchExpressions:
                  - key: accelerator
                    operator: In
                    values: ["nvidia-a100"]
      containers:
        - name: vllm
          image: vllm/vllm-openai:latest
          resources:
            limits:
              nvidia.com/gpu: 1
          ports:
            - containerPort: 8000
```
      </Fragment>
    </Row>

      <p slot="docs">Gerencie taints com kubectl. Adicione taints para repelir Pods, remova taints (com sufixo menos) para permitir agendamento.</p>
      <Fragment slot="code">
```bash
$ kubectl taint nodes worker-1 dedicated=gpu:NoSchedule
node/worker-1 tainted

$ kubectl describe node worker-1 | grep -A3 Taints
Taints:             dedicated=gpu:NoSchedule

$ kubectl taint nodes worker-1 dedicated=gpu:NoSchedule-
node/worker-1 untainted
```
