<Intro>
  <p>Namespaces particionam um cluster em sub-clusters virtuais. Eles fornecem escopo para nomes e são a base para resource quotas e políticas RBAC.</p>
</Intro>

<table class="example-table">
  <tbody>
    <FileHeader filename="namespace.yaml" />
    <Row>
      <p slot="docs">Um Namespace é um recurso core do Kubernetes (API <code>v1</code>).</p>
      <Fragment slot="code">
```yaml
apiVersion: v1
kind: Namespace
```
      </Fragment>
    </Row>
    <Row>
      <p slot="docs">O <code>name</code> deve ser único no cluster. Use apenas minúsculas, números e hífens.</p>
      <Fragment slot="code">
```yaml
metadata:
  name: my-app
```
      </Fragment>
    </Row>
    <Row last>
      <p slot="docs">Labels ajudam a organizar e selecionar namespaces. Padrões comuns: environment, team, cost-center.</p>
      <Fragment slot="code">
```yaml
  labels:
    environment: production
    team: platform
```
      </Fragment>
    </Row>
  </tbody>
</table>

<table class="example-table">
  <tbody>
    <TerminalHeader cmd="kubectl get namespaces" />
    <Row last terminal>
      <p slot="docs">Namespaces built-in: <code>default</code> (seus recursos se não especificado), <code>kube-system</code> (control plane), <code>kube-public</code> (legível por todos).</p>
      <Fragment slot="code">
```bash
$ kubectl get namespaces
NAME              STATUS   AGE
default           Active   45d
kube-system       Active   45d
kube-public       Active   45d
kube-node-lease   Active   45d
```
      </Fragment>
    </Row>
  </tbody>
</table>

      <Fragment slot="code">

      </Fragment>

<table class="example-table">
  <tbody>
    <FileHeader filename="pod.yaml" />
    <Row>
      <p slot="docs">Dentro do mesmo namespace, referencie services apenas pelo nome. O DNS do Kubernetes resolve automaticamente.</p>
      <Fragment slot="code">
```yaml
env:
  - name: API_URL
    value: "http://api:8080"
```
      </Fragment>
    </Row>
    <Row>
      <p slot="docs">Referências cross-namespace usam o formato <code>service.namespace.svc</code>.</p>
      <Fragment slot="code">
```yaml
  - name: REDIS_URL
    value: "redis://redis.cache.svc:6379"
```
      </Fragment>
    </Row>
    <Row last>
      <p slot="docs">O FQDN completo inclui <code>.cluster.local</code>. Geralmente só necessário para casos especiais.</p>
      <Fragment slot="code">
```yaml
  - name: DB_HOST
    value: "postgres.db.svc.cluster.local"
```
      </Fragment>
    </Row>
  </tbody>
</table>

<table class="example-table">
  <tbody>
    <FileHeader filename="resourcequota.yaml" />
    <Row>
      <p slot="docs">ResourceQuotas limitam o consumo total de recursos por namespace. Previne que um time consuma todos os recursos do cluster.</p>
      <Fragment slot="code">
```yaml
apiVersion: v1
kind: ResourceQuota
metadata:
  name: compute-quota
  namespace: my-app
```
      </Fragment>
    </Row>
    <Row last>
      <p slot="docs"><code>spec.hard</code> define os limites. Restrinja CPU, memória, storage e contagem de objetos.</p>
      <Fragment slot="code">
```yaml
spec:
  hard:
    requests.cpu: "10"
    requests.memory: 20Gi
    limits.cpu: "20"
    limits.memory: 40Gi
    pods: "50"
```
      </Fragment>
    </Row>
  </tbody>
</table>

<table class="example-table">
  <tbody>
    <FileHeader filename="limitrange.yaml" />
    <Row>
      <p slot="docs">LimitRanges definem limits e max/min padrão de recursos por container.</p>
      <Fragment slot="code">
```yaml
apiVersion: v1
kind: LimitRange
metadata:
  name: default-limits
spec:
  limits:
```
      </Fragment>
    </Row>
    <Row>
      <p slot="docs"><code>default</code> define limits quando não especificados.</p>
      <Fragment slot="code">
```yaml
    - default:
        cpu: "500m"
        memory: "512Mi"
```
      </Fragment>
    </Row>
  </tbody>
  <tbody>
    <Row last>
      <p slot="docs"><code>defaultRequest</code> define requests.</p>
      <Fragment slot="code">
```yaml
      defaultRequest:
        cpu: "100m"
        memory: "128Mi"
      type: Container
```
      </Fragment>
    </Row>
  </tbody>
</table>

    <TerminalHeader cmd="kubectl api-resources --namespaced=false" />
    <Row last terminal>
      <p slot="docs">Alguns recursos são de escopo de cluster: Nodes, PersistentVolumes, ClusterRoles, Namespaces.</p>
      <Fragment slot="code">
```bash
$ kubectl api-resources --namespaced=false
NAME                  SHORTNAMES   APIVERSION   NAMESPACED
nodes                 no           v1           false
persistentvolumes     pv           v1           false
clusterroles                       rbac/v1      false
namespaces            ns           v1           false
```
      </Fragment>
    </Row>
  </tbody>
</table>

<table class="example-table">
  <tbody>
    <TerminalHeader cmd="kubectl api-resources --namespaced=true" />
    <Row last terminal>
      <p slot="docs">A maioria dos recursos de workload são namespaced: Pods, Services, Deployments, ConfigMaps.</p>
      <Fragment slot="code">
```bash
$ kubectl api-resources --namespaced=true
NAME                  SHORTNAMES   APIVERSION   NAMESPACED
pods                  po           v1           true
services              svc          v1           true
deployments           deploy       apps/v1      true
configmaps            cm           v1           true
```
      </Fragment>
    </Row>
  </tbody>
</table>
