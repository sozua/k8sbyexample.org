<Intro>
  <p>Deployments manage Pods via ReplicaSets. The hierarchy is: Deployment → ReplicaSet → Pods. Deployments add self-healing, scaling, rolling updates, and rollbacks on top of ReplicaSets.</p>
</Intro>

<table class="example-table">
  <tbody>
    <FileHeader filename="deployment.yaml" />
    <Row>
      <p slot="docs">Deployments use the <code>apps/v1</code> API. The selector links the Deployment to its Pods.</p>
      <Fragment slot="code">
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
  labels:
    app.kubernetes.io/name: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app.kubernetes.io/name: my-app
```
      </Fragment>
    </Row>
    <Row last>
      <p slot="docs">The Pod template defines what each replica looks like. Labels in the template must match the selector.</p>
      <Fragment slot="code">
```yaml
  template:
    metadata:
      labels:
        app.kubernetes.io/name: my-app
    spec:
      containers:
        - name: app
          image: my-app:v1.2.0
          ports:
            - name: http
              containerPort: 8080
```
      </Fragment>
    </Row>
  </tbody>
</table>

    <FileHeader filename="rolling-update-strategy.yaml" />
    <Row>
      <p slot="docs">Two update strategies: <code>RollingUpdate</code> (default) gradually replaces Pods; <code>Recreate</code> kills all Pods before creating new ones.</p>
      <Fragment slot="code">
```yaml
spec:
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxUnavailable: 0
      maxSurge: 1
```
      </Fragment>
    </Row>
    <Row last>
      <p slot="docs"><code>minReadySeconds</code> delays marking Pods as ready. <code>revisionHistoryLimit</code> controls how many old ReplicaSets to keep for rollback.</p>
      <Fragment slot="code">
```yaml
  replicas: 3
  minReadySeconds: 10
  revisionHistoryLimit: 5
```
      </Fragment>
    </Row>
  </tbody>

    <Row last terminal>
      <p slot="docs">Rollbacks are fast because old ReplicaSets still exist. Kubernetes just scales them up and down.</p>
      <Fragment slot="code">
```bash
$ kubectl rollout undo deployment/my-app
deployment.apps/my-app rolled back

$ kubectl rollout undo deployment/my-app --to-revision=2
deployment.apps/my-app rolled back to revision 2
```

```bash

deployment.apps/my-app image updated

$ kubectl rollout pause deployment/my-app
deployment.apps/my-app paused

$ kubectl rollout resume deployment/my-app
deployment.apps/my-app resumed
```
