<Intro>
  <p>LoadBalancer provisions an external load balancer from your cloud provider (AWS ELB, GCP LB, Azure LB). Traffic is routed to your Pods. Only works in supported environments.</p>
</Intro>

<table class="example-table">
  <tbody>
    <FileHeader filename="service-loadbalancer.yaml" />
    <Row last>
      <p slot="docs">Set <code>type: LoadBalancer</code> to provision a cloud load balancer. The cloud controller creates and configures the LB automatically.</p>
      <Fragment slot="code">
```yaml
apiVersion: v1
kind: Service
metadata:
  name: my-app
spec:
  type: LoadBalancer
  ports:
    - port: 80
      targetPort: 8080
  selector:
    app: my-app
```
      </Fragment>
    </Row>
  </tbody>
</table>

  <tbody>
    <TerminalHeader cmd="kubectl get svc my-app -w" />
    <Row last terminal>
      <p slot="docs">The external IP appears in the Service status once provisioned. This can take a few minutes depending on the cloud provider.</p>
      <Fragment slot="code">

    <FileHeader filename="service-lb-aws.yaml" />
    <Row last>
      <p slot="docs">Cloud-specific annotations configure the load balancer. Each provider has different options for internal LBs, NLB vs ALB, etc.</p>
      <Fragment slot="code">
```yaml
apiVersion: v1
kind: Service
metadata:
  name: my-app
  annotations:
    service.beta.kubernetes.io/aws-load-balancer-type: nlb
    service.beta.kubernetes.io/aws-load-balancer-internal: "true"
spec:
  type: LoadBalancer
  ports:
    - port: 80
      targetPort: 8080
  selector:
    app: my-app
```
      </Fragment>
    </Row>
  </tbody>
</table>

<table class="example-table">
  <tbody>
    <FileHeader filename="service-external-traffic.yaml" />
    <Row>
      <p slot="docs"><code>externalTrafficPolicy: Cluster</code> (default) load balances across all nodes. Traffic may hop between nodes, causing extra latency and losing source IP.</p>
      <Fragment slot="code">
```yaml
spec:
  type: LoadBalancer
  externalTrafficPolicy: Cluster
```
      </Fragment>
    </Row>
    <Row last>
      <p slot="docs"><code>externalTrafficPolicy: Local</code> routes traffic only to nodes with pods. Preserves source IP and reduces latency, but requires pods on all receiving nodes.</p>
      <Fragment slot="code">
```yaml
spec:
  type: LoadBalancer
  externalTrafficPolicy: Local
  ports:
    - port: 80
      targetPort: 8080
  selector:
    app: my-app
```
      </Fragment>
    </Row>
  </tbody>
</table>

      <p slot="docs">With <code>Local</code> policy, check that pods run on nodes receiving traffic. Use DaemonSet or pod anti-affinity to ensure coverage. Nodes without pods return connection refused.</p>
      <Fragment slot="code">
```bash
$ kubectl get svc my-app -o yaml | grep externalTrafficPolicy
  externalTrafficPolicy: Local

$ kubectl get pods -o wide -l app=my-app
NAME       NODE      IP
my-app-1   node-1    10.244.1.5
my-app-2   node-2    10.244.2.8

$ kubectl logs my-app-1
Received request from 203.0.113.50
```
