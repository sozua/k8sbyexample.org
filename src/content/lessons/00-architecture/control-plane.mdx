<Intro>
  <p>The control plane makes global decisions about the cluster. It consists of: API Server (communication hub), etcd (state store), Scheduler (Pod placement), Controller Manager (reconciliation loops). Usually runs on dedicated nodes.</p>
</Intro>

    <FileHeader filename="scheduler-workflow.txt" />
    <Row>
      <p slot="docs">The Scheduler assigns Pods to nodes. It watches for unscheduled Pods, filters nodes by constraints, scores remaining nodes, then binds Pod to best node.</p>
      <Fragment slot="code">
```
Filtering (hard constraints):
- Resource requests fit available
- Node selectors match
- Taints tolerated
- Affinity rules satisfied
```
      </Fragment>
    </Row>
    <Row last>
      <p slot="docs">Scoring ranks nodes by soft preferences. Highest score wins.</p>
      <Fragment slot="code">
```
Scoring (soft preferences):
- Resource balance across nodes
- Pod topology spread
- Node affinity preferences
```
      </Fragment>
    </Row>
  </tbody>
</table>

    <Row last>
      <p slot="docs">Controller Manager runs control loops that watch state and reconcile current state toward desired state. Each controller handles one resource type.</p>
      <Fragment slot="code">
```
Controllers in kube-controller-manager:
- Deployment controller    → manages ReplicaSets
- ReplicaSet controller    → ensures Pod count
- Node controller          → monitors node health
- Service controller       → creates cloud LBs
- Endpoint controller      → populates Endpoints
- Job controller           → runs to completion
- StatefulSet controller   → ordered Pod management
```
      </Fragment>
    </Row>

Cloud Controller Manager:

      <p slot="docs">High availability requires 3+ control plane nodes. API Servers run behind a load balancer. etcd needs odd number for quorum. Scheduler and Controller Manager use leader election.</p>
      <Fragment slot="code">
```
HA Control Plane (3 nodes minimum):

┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│   Node 1     │  │   Node 2     │  │   Node 3     │
│ ┌──────────┐ │  │ ┌──────────┐ │  │ ┌──────────┐ │
│ │API Server│ │  │ │API Server│ │  │ │API Server│ │
│ └────┬─────┘ │  │ └────┬─────┘ │  │ └────┬─────┘ │
│ ┌────┴─────┐ │  │ ┌────┴─────┐ │  │ ┌────┴─────┐ │
│ │   etcd   │◄┼──┼►│   etcd   │◄┼──┼►│   etcd   │ │
│ └──────────┘ │  │ └──────────┘ │  │ └──────────┘ │
│ Scheduler(L) │  │ Scheduler    │  │ Scheduler    │
│ Controller(L)│  │ Controller   │  │ Controller   │
└──────────────┘  └──────────────┘  └──────────────┘
    (L) = Leader
```
