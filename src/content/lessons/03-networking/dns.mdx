<Intro>
  <p>Kubernetes runs CoreDNS for internal name resolution. Every Service gets a DNS A record automatically. Pods resolve Service names to ClusterIPs without hardcoding addresses.</p>
</Intro>

    <FileHeader filename="service.yaml" />
    <Row last>
      <p slot="docs">Services automatically get DNS records. This Service gets DNS: <code>my-app.production.svc.cluster.local</code> with an A record pointing to the ClusterIP.</p>
      <Fragment slot="code">
```yaml
apiVersion: v1
kind: Service
metadata:
  name: my-app
  namespace: production
spec:
  ports:
    - port: 80
  selector:
    app: my-app
```
      </Fragment>

    <TerminalHeader cmd="curl http://my-app" />
    <Row last terminal>
      <p slot="docs">DNS resolution from shortest to FQDN. Same namespace: just service name. Cross-namespace: <code>service.namespace</code>. With svc suffix: <code>service.namespace.svc</code>. Full FQDN (rarely needed): <code>service.namespace.svc.cluster.local</code>.</p>
      <Fragment slot="code">
```bash
$ curl http://my-app
Hello from my-app!

$ curl http://my-app.other-namespace
Hello from my-app!

$ curl http://my-app.other-namespace.svc

$ curl http://my-app.other-namespace.svc.cluster.local
```
      </Fragment>
    </Row>
  </tbody>
</table>

      <Fragment slot="code">
```bash

Address:   10.96.0.10#53

Name:      my-app.default.svc.cluster.local
Address:   10.96.0.100

$ nslookup -type=SRV _http._tcp.my-app.default.svc.cluster.local
_http._tcp.my-app.default.svc.cluster.local   SRV 0 100 80 my-app.default.svc.cluster.local
```

    <FileHeader filename="headless-service.yaml" />
    <Row last>
      <p slot="docs">Headless Services (<code>clusterIP: None</code>) return Pod IPs directly instead of a ClusterIP. DNS returns all matching Pod IPs. Essential for StatefulSets and client-side load balancing.</p>
      <Fragment slot="code">
```yaml
apiVersion: v1
kind: Service
metadata:
  name: my-db
spec:
  clusterIP: None
  ports:
    - port: 5432
  selector:
    app: postgres
```
      </Fragment>
    </Row>
  </tbody>
</table>

    <FileHeader filename="pod-dns-config.yaml" />
    <Row last>
      <p slot="docs">Pod DNS policy controls how Pods resolve names. <code>ClusterFirst</code> is default. Use <code>None</code> with custom <code>dnsConfig</code> for special cases. Options: Default, ClusterFirst, ClusterFirstWithHostNet, None.</p>
      <Fragment slot="code">
```yaml
spec:
  dnsPolicy: ClusterFirst
  dnsConfig:
    nameservers:
      - 8.8.8.8
    searches:
      - my-namespace.svc.cluster.local
    options:
      - name: ndots
        value: "5"
```
      </Fragment>
    </Row>
  </tbody>
</table>

    <TerminalHeader cmd="kubectl get configmap coredns -n kube-system" />
    <Row last terminal>
      <p slot="docs">CoreDNS configuration is in a ConfigMap in kube-system. Customize for external DNS forwarding, custom domains, or caching. Pods get <code>/etc/resolv.conf</code> configured by kubelet.</p>
      <Fragment slot="code">
```bash
$ kubectl get configmap coredns -n kube-system -o yaml
apiVersion: v1
kind: ConfigMap
data:
  Corefile: |
    .:53 {
        kubernetes cluster.local in-addr.arpa ip6.arpa {
           pods insecure
           fallthrough in-addr.arpa ip6.arpa
        }
        forward . /etc/resolv.conf
        cache 30
    }

$ kubectl exec my-pod -- cat /etc/resolv.conf
nameserver 10.96.0.10
search default.svc.cluster.local svc.cluster.local cluster.local
```

    </Row>
